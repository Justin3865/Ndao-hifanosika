# Guide utilisateur — Ndao Hifanosika

## 1. Se connecter
Adresse de la plateforme → **Se connecter** → e-mail et mot de passe (si la double authentification est activée : code à 6 chiffres). Mot de passe oublié ? Utilisez le lien « Mot de passe oublié ? ». Pas de compte : **Créer un compte**, puis attendez la validation d'un administrateur.

## 2. Changer de langue
Le sélecteur **FR / MG** en haut de l'écran traduit toute l'interface en malgache (Tetikasa, Hetsika, Mpahazo tombontsoa, Fanombanana, Tatitra…). Votre choix est mémorisé. Certains textes saisis par les utilisateurs restent dans leur langue d'origine.

## 3. Ce que vous voyez dépend de votre rôle
- **Coordinateur** : uniquement les projets qui vous sont affectés (listes, tableau de bord, rapports, carte des zones). Les pages d'analyse globales (résumé IA, anomalies…) ne sont pas disponibles pour vous : un message l'indique. Utilisez les vues par projet.
- **Direction, administrateur** : vue d'ensemble de tous les projets.
- **Autres rôles** : selon votre fonction.

## 4. Données des enfants et des femmes vulnérables
Pour protéger ces personnes, certaines informations apparaissent **masquées** selon votre rôle :
- initiales au lieu du nom (« R. A. ») ;
- téléphone et e-mail partiels (••••••••67), CIN partiel ;
- position sur la carte arrondie, adresse exacte non affichée ;
- année de naissance seulement.
Le symbole « ••• » indique une donnée masquée. Si vous avez besoin de l'information pour votre travail, demandez à votre coordinateur ou à un administrateur. **Ne copiez jamais** une valeur masquée dans une fiche : elle sera refusée.
Les lectures de ces données sont **journalisées** pour la sécurité des bénéficiaires. Ne partagez pas d'informations personnelles par messagerie non sécurisée et ne prenez pas de capture d'écran de fiches d'enfants.

## 5. Tâches courantes
| Je veux… | Où / comment |
|---|---|
| Voir mes projets | **Projets** (menu), recherche en haut de la liste |
| Ajouter un bénéficiaire | **Bénéficiaires → Ajouter un bénéficiaire** : nom, genre, date de naissance (l'âge se calcule), CIN à 12 chiffres, téléphone à 10 chiffres |
| Enregistrer le statut du parcours | fiche du bénéficiaire (statut du parcours) : *actif*, *terminé* ou *abandon* (date + motif en cas d'abandon). Ces statuts servent à évaluer le risque d'abandon : renseignez-les avec soin |
| Faire une enquête de terrain | **Ma mission (GPS)** ; partagez votre position seulement si vous le souhaitez, vous pouvez l'arrêter à tout moment |
| Consulter la carte des zones | **Zones d'intervention** / **Vulnérabilité par zone** |
| Produire un rapport | **Rapports** → type, période → **Générer le rapport** → **Télécharger le PDF** |
| Lire mes notifications | icône cloche ; **Marquer comme lu**, **Archiver** |
| Changer mon mot de passe | **Paramètres → Sécurité** (12 caractères minimum) |

## 6. Comprendre les alertes d'IA
Le **risque d'abandon** est un score de 0 à 100 calculé par des règles (projet suspendu, jalons en retard, évaluations faibles, vulnérabilité, très jeune âge). « Élevé » à partir de 60. C'est une **aide pour décider qui visiter en priorité**, pas un jugement sur la personne : vérifiez toujours sur le terrain. Un score peut être faux ; signalez les incohérences à votre coordinateur.

## 7. En cas de problème
« Accès refusé » : la donnée est hors de votre périmètre. « Valeur masquée » : voir §4. Page vide : vérifiez que des projets vous sont affectés. Autre : contactez le DSI avec la page, l'heure et ce que vous faisiez.
